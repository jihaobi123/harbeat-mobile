# V3 接入原播放页（0.1.5+6）

用户要求将 V3 直接接入现有前端播放页，允许小幅调整组件。

## 最终交互

- 原 `MAKE THE FLOOR MOVE.` 页面、蓝色播放卡、荧光黄控件、底部导航保留。
- 顶部增加“标准播放 / V3 实时混音”模式选择；推荐页的 V3 按钮也进入这个播放页。
- 原开始/暂停、下一首和进度显示驱动 V3 同一个会话。转场结束后自动更新歌曲、作者、BPM、时长与播放位置。
- V3 能量控件使用“提高 / 降低”，与算法的相对能量意图一致；风格为已有素材支持的 Trap / Grime。
- 原循环位置改为 10/18/30 秒等待预算。新增停止、当前交接状态、取消、六首选曲和日志保存。
- V3 六首是候选池，按实时意图与窗口评分选曲；不显示无效的顺序、循环、随机、删队列或拖动排序功能。
- 切换“音乐”页保持同一会话，迷你播放器控制 V3。播放其他普通音频前先停止 V3。锁屏或退到桌面仍暂停。

## 实现

最新算法仍固定在上游 `279b65da50d436586c220fb38befdb03f6571099`，其 planner、DSP、cache、AudioWorklet 的字节校验不变。

`RealtimeMixEngine` 附着 MainActivity，使用本地安全来源加载无界面的 `engine.html`。Flutter 通过方法通道发播放、暂停、方向、取消、选曲、停止和导出命令；事件通道每 250 ms 更新状态。该 WebView 不显示独立界面、不接收用户触控，也不访问网络。

移除了 RealtimeMixActivity 导航和 manifest 入口。可见页面完全由既有 Flutter 前端渲染，未把另一套 HTML 页面嵌到播放卡中。
