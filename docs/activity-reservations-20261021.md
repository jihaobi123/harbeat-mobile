# 预约与保留 set（2026-10-21）

入口为“我的 → 我的预约”。云端网页地址：https://8.136.120.255/listen/app/ 。本机测试地址仍为 http://127.0.0.1:8766/ 。

新建时选择风格、能量、时间、时长和候选数量（4、8、12 首）。服务器收到预约后立即准备，按活动开始时间排列等待队列；页面关闭不影响准备。活动结束只改变显示状态，set 和预约记录继续保留。“再次预约这个 set”新增时间记录，引用原素材包，不重渲染已经成功的交接。

当前使用私人工作区，凭据保存于设备安全存储。普通本地状态只保存预约摘要。换浏览器或安卓设备时，在旧设备导出私人预约备份，再在新设备恢复；备份包含访问凭据，不能公开分享。当前尚未接账号同步。

服务器与手机的准备进度分开显示。“云端候选与素材”记录候选准备结果；“下载本机素材”下载并逐个校验音频，不把整套音频同时解码到内存。独立预约编码缓存最多 1 GiB、2048 个片段，新增占用不超过设备剩余配额的 80%。容量不足或系统清理会显示部分完成，余下仍需联网读取。缓存下载在页面转后台时暂停，可以重新准备。播放页另外显示当前附近已经解码和处理好的接点数量，详见 [本机准备状态](reservation-device-readiness-20261021.md)。

## 混音规则

预约使用现有正式 TypeScript planner，保留速度、拍点、音量连续性、选点和整段人声冲突检查。候选最多 12 首，每首取八个时间区域，每区域保留最多三首不同候选，每首最多 24 个、全套最多 288 个候选接点。空缺区域如实记录；新增候选为小体积策略资料，不为每个接点单独渲染成品 WAV。旧预约保留原播放入口，点“准备更多接点”才重新规划。

播放时按当前进度滚动预热近期候选，自动和手动接歌共用准备池。只有曲对、窗口、起止时间、速度和分析来源都一致，且 PCM 仍保留在内存时，才复用已准备结果。手动下一首继续寻找附近合格接点，不会为复用旧素材跳回过去的位置；也不会在用户点击时硬切。后台预热遇到不同的前台请求会让出准备资源，相同请求共用处理。素材赶不上接点时，继续当前音乐，使用同接点原渐混或寻找后续合格接点。

已接入的六项方法为原渐混、独立贝斯交接、旋律滤波、旋律让位、人声唱完再退出、贝斯交接加旋律滤波；选择仍由现有分析指标和素材资格决定。

素材包保存候选、覆盖范围和音源指纹，同源分轨由歌曲复用；旧成品转场仍兼容。已下载的预约音频独立保留，不受普通播放缓存淘汰影响。曲库增加新的无关素材不会使旧 set 失效；原报告或音源改变时显示需要更新，避免旧交接与新音源混用。
