# Android 连续衔接排查与 0.3.0 部署（2026-10-21）

## 范围与来源

以 `e86de81`（0.3.0+17）为基础，接入远端最新的 Jetson 审批、手机执行方案。Jetson 输出来源绑定的控制计划；手机校验素材并用同一个 WebAudio 时钟执行。原有风格、能量与播放页面保持。

## 旧手机现场

升级前先导出 0.2.1+16 的现场，未先清空数据或重新开始播放。记录包含两次 track_start、六次交接和多次暂停/恢复。不能据此将整份记录视为一次无中断连续测试。

最早的“两次交接后停住”发生在 DjAspro (Track 2)：从源位置 68.313 秒接管，137.353 秒结束，暂停时计算源位置 137.325 秒，符合播放器的结束阈值。继续按钮会重新遇到结束条件，立即再次暂停。其最后一段 120–137.353 秒已提前排入；重读服务端同一 FLAC 得到 200、2,149,915 字节且 SHA-256 一致。因此这个结束点不是最后一段素材未下载。

旧版暂停事件没有原因，其他中途暂停不能归因为网络、焦点或用户操作。系统 AudioTrack 的 zero-data 行也可能来自同时存在的空闲原生音轨，不能单独证明 WebAudio 静音。旧版 observation.peak 是整场最大值，不能证明该时刻有声。

证据摘要：`outputs/Android-0.3.0-stop-diagnosis-20261021.json`。原始会话与日志只保留在本机 debug-output，未上传。

## 修复

- 自动规划原先一律从“当前位置 +35 秒”开始，底层还要求冷素材提前量；短曲后段会因此漏掉仍可用的接点。现在优先保留宽裕准备时间，若无结果，再从真实当前位置回查，保留原有拍点、人声、变速、响度和准备时间检查。
- 使用当前服务端同一首 DjAspro 和原来六首相容音乐回放，在源位置 90 秒，旧逻辑 0 个结果，修复后 174 个合格窗口，首选 HIPHOP 的 108.770 秒接点。这是当前数据回放，不能当作历史服务器状态的完整重建。
- 后台或焦点中断发生在准备阶段时，已有播放轨保留供手动恢复，避免因为 busy 而清空当前音乐。
- 前台等待缓冲时保留亮屏；主动暂停仍允许熄屏。后台、失去焦点、耳机拔出后仍暂停，不强制恢复播放。
- 导出暂停原因、AudioContext 状态、缓冲开始/恢复、分段覆盖和自动无候选原因。新增手机专用 worklet 每 5 秒记录输出峰值/RMS；原有固定 SHA 的上游 worklet/DSP 文件不变。
- Android 每 10 秒输出精简 HarBeatPlayback 诊断，便于区分进度、缓冲、选曲和实际数字音频输出。

## 新版服务实测与续播修复

安装第一轮 0.3.0 后从头播放 24K Magic，确实重现了没有下一首的情况。新诊断记录显示所有原曲分段覆盖至 225.983 秒，无缓冲、无分段错误、无迟到标记，输出 RMS 在播放中持续非零。随后明确记录 pause.reason=track-ended，而不是下载等待。

该歌曲虽然在 `/listen/library.json` 标为 mixStatus=ready，却缺少 `/listen/execution/index.json` 中的审批资料，所有从它发起的 `/plans` 请求都返回 422。复用真实 A/B 元数据在本机执行服务端基础接点校验能够通过，缺口在新执行发布链路。当前公开索引共有 159 首，执行索引有 153 个分析资料条目，只有 9 首发布了端侧分轨音频。其他歌曲不能仅凭旧 mixStatus 宣称新版整条链路已就绪。

另测一组 Straight→HIPHOP 新审批任务进入队列后失败；公共 API 隐藏了私有错误原因，未取得此 Windows 可用 SSH 连接前，不将其武断归因为某个 NAS 文件。HIPHOP→Make It Right 的另一新接点 113.257 秒任务能够算出 ready，说明并非所有新任务都失败。

因此补上了两项实际修复：

- 加载真实执行发布目录，缺少分析资料的歌仍保留原曲播放，但不冒充可混音候选；预热也不再反复请求未发布的当前歌。
- 自动模式混音准备失败时，提前准备下一首完整原曲并在当前歌的自然结尾，用同一音频时钟安排顺序续播。没有构造未经审批的混音片段；sequential_scheduled/complete 明确标 mixed=false。暂停、关闭自动、换方向和停止仍受原有控制。歌曲已经结束后再按播放，会续播下一首，避免原地恢复后立刻又暂停。

新增测试覆盖执行目录缺失、目录网络失败、五首原曲按结尾时钟续播、取消/暂停与已结束恢复。新增续播是可靠性兜底，不能算作 Jetson 已审批的实时混音成功。
