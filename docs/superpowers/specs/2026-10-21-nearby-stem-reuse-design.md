# 新前端复用既有混音方案

用户要求复用已经测试的逻辑，前端负责接入，不另创效果或阈值。现有正式规则为 metric-mix-v1.0，包含原渐混、独立贝斯、other 滤波、other 让位、人声交接及贝斯加滤波。保留正式选材、接点、人声门槛和所有 DSP 参数；尚未纳入该规则的实验不自动开启。

当前即时 Next 与方向变化路径只使用 localOriginal，只有内存已有结果恰好同点时才能复用分轨。修复在已选同一接点内有界尝试云端结果，提前准备本地原渐混作为后备；云端推荐方法与其对应音频、B 正文全部装入后才算可用。等待上限为两秒，并在接点前保留一秒安排时间，不能因此移动选点或改 B 素材。原渐混准备与云端准备并行；云端失败、队列未完成或下载未完成时保留同点后备。一个显式请求最多尝试一次云端任务，后续过期重试不继续增加队列。

保留旧 cloud validatePrepared 和 worker choose_method，客户端不重新评分效果。结果与计划的来源、窗口、起止、B 片段、速率和时长必须匹配。已有就绪同点结果继续直接复用。暂停、换方向、停止和来源变化会取消两条准备路径；晚回来的结果不能安排或覆盖新方向。

记录云端请求确认、任务状态变化、结果完成、选中音频装入及原渐混回退原因，区分未请求、排队/渲染、下载与预算耗尽。诊断只记录本曲对任务，不采集其他浏览信息。新页面仍使用既有结果/方法展示，不引入新交互。

验证用失败回归覆盖准备好的非原版、下载未完成、慢任务后备、方向取消及结果不匹配；运行引擎测试/类型检查/构建，并在新页面完成真实分轨交接及记录导出。测量实际 worker 阶段与公网单片下载，不能用一次测速推断购买带宽规格，也不能将固定试听素材的及时性推广到所有实时接点。
