# Jetson 判断与手机执行，0.3.0+17

云端入口：[HarBeat](https://8.136.120.255/listen/app/)。

Jetson 核对 NAS 原曲、报告、分轨及档案，重建具体接点，计算声部重叠、音高差、人声退出和手法资格，输出 JSON 控制方案。手机核验后下载源片段，使用同源 WSOLA 保调变速，在一个 Web Audio 时钟上执行增益、EQ、滤波和正文接管。现场选择仍遵守原有拍点、人声及方向规则。

## 预约与现场操作

新预约保存多个接点的完整批准，按接点记录进度并支持断点恢复。“源素材齐”和“编排齐”分别计数，全部批准完成才记 ready。旧 v2 预约保持可读、可复用；详情页提供“准备 Jetson 混音编排”，升级保留原曲目和初始曲。

手机先预热一个未来有效、方向合格的已批准预约点，随后预热当前最近点和同目标后继点。最多三份 PCM，仍受 96 MiB 窗口预算限制。自动与手动共用批准和素材，缓存不会改变实际选点规则。缺少批准时继续当前音乐，等待后续合格接点；缺少分轨时，只能采用同接点已批准的原渐混后备。

批准缓存绑定双方原曲、报告、分轨、manifest 和 profile 指纹。档案更新后，旧云缓存失效，手机也会重新核验。服务重启后的遗留运行状态转为可重试失败。

## 实测与边界

HIPHOP → Make It Right 保留 A=40.83718820861678 秒、B=9.26 秒的接点。Jetson 与旧设备路径的四项指标最大误差为 2.22e-16，均推荐旋律滤波。真实浏览器已完成交接到 B 正文，日志标记 `musicAnalysis: jetson`、`renderRequested: false`，没有请求成品转场渲染。证据见本目录的 migration / browser-execution JSON。

迁移修复了两个边界：拍格允许的提前量曾生成 -37 毫秒控制时间，现从窗口零点执行，主接点不变；不同 JS 引擎的 EQ 计算相差 3.33e-16，现允许 1e-9 数值容差，结构、字符串、来源及原始方案指纹仍严格核验。

生产预约 Worker 在隔离存储中完成了一接点的提交、轮询、校验和封存，模拟 checkpoint 重启后恢复成功。禁网后的端侧自动／手动均能复用同一批准。这是代表性一接点验收，不能据此声称大型预约或整个曲库已全部准备完成。

验证：TypeScript 343 通过、3 项跳过；后端相关 53、预约服务 63、预览代理 10、Flutter 157 通过。TypeScript / Flutter 静态检查通过。Android 素材校验覆盖 260 个文件、160 个来源指纹。未编译 APK，未做安卓真机长时间播放验收。

## 鼓声部提前叠放

[云端试听](https://8.136.120.255/listen/app/drum-prelude/drum-prelude-audition.html)；本机服务运行时可用[本机试听](http://127.0.0.1:6218/drum-prelude-audition.html)。两端分别保存选择。

每组比较原渐混、历史受益单项，以及同一单项加 B 自然鼓提前进入。鼓用一小节从 0 增至 0.25，保持两小节，再接入原主窗口。三版使用相同源映射、主接点、其他曲线、EQ 和人声规则，之后接相同八秒 B 原速正文。新鼓层仅供独立试听，未进入自动播放。

9 个固定曲对中只有 2 组通过，未达到原定 6 组：Doin' It → Talgo、GOOD BOY → Snake Gang，历史单项均为人声交接。其余 3 组未通过当前主接点响度／人声校验，2 组历史单项未达到暂定门槛，2 组缺少连续三小节前置结构。保持接点并跳过，未更换手法凑数。逐组结果见 `drum-prelude-audit-20261021.json`。

鼓的节奏密度、重音一致性和 RBJ 峰值／能量检查属于技术代理，不能保证听感顺畅。两组采用同源声部窗口，由网页执行三版，没有生成成品转场。实验保留 1de11515269f… 版本；生产最终 Node 为 92dba192dd82…，两者差异是 EQ 回放浮点校验，音乐判断定义相同。

## 构建与部署

Windows 构建前运行 `python tools/build_realtime.py --download`，再运行 `python tools/verify_android_bundle.py`。APK 编译和手机验收步骤见 `windows-pre-apk-20261021.md`。

`python tools/build_jetson_planner.py` 生成 Jetson 固定 CLI。Python runner 核验来源并提供临时 PCM，标准任务仅输出 JSON；`--audition-output` 是内部试听素材导出入口。后端环境变量见客户端仓库 `deploy/metric-mix/JETSON_PLANS.md`。本轮未重启 GPU、下载或导入 worker。
