# 0.1.9+11 · 黑胶陈列与展开歌单

延续用户提供的音乐播放器参考图，将收藏和歌单入口改成黑胶陈列，展开页采用左侧唱片轨道、右侧挂环歌曲卡片。页面继续使用现有真实曲库、歌单和播放控制器。

## 页面与交互

- 收藏和歌单显示露出黑胶的彩色封套、唱片纹路与陈列架横线。没有专辑字段或封面来源时，使用原生图形封套，不把歌曲虚构成新专辑。
- 打开封套时，通过共享唱片元素与淡入动画进入展开页；左侧轨道滑入，右侧歌曲卡片依次滑入。右侧卡片保留细描边、偏移彩色纸层、横向挂环、小封面、歌名、艺人、真实时长和独立播放键。未知时长显示待加载。
- 左侧黑胶只在当前唱片实际播放时旋转，暂停、页面不可见或系统减少动态效果时停止。减少动态效果时直接展示展开结果。
- 单曲播放、暂停、播放全部、加入队列、上一首/下一首复用原控制器。播放时留在展开页面，返回陈列页不会中断音频。
- 右上角管理入口提供歌曲详情、上移、下移与从歌单移除；长按拖动排序继续可用。重命名、删除与新建歌单仍在陈列页。未加载歌曲 ID 保留，数量和空态明确提示。
- 收藏中的唱片打开后选中所点歌曲；下一首和上一首限定于当前收藏/歌单的标准播放队列。V3 操作继续遵守现有引擎的选曲与交接逻辑。
- 360/390/430 宽度及 1.5 倍文字采用不同轨道宽度，给歌曲内容留出空间。文字与按钮保持水平，只有底纸略微倾斜。切换推荐/搜索/收藏/歌单会重置该分区滚动，避免长列表切换为短列表时的布局纠正循环。

## 真机动效恢复（2026-10-16）

用户反馈手机没有过渡动画后，检查发现 MIX 4 的 `animator_duration_scale`、`transition_animation_scale`、`window_animation_scale` 均为 `0`。其中关闭 Animator 动画会使 Flutter 的 `MediaQuery.disableAnimationsOf(context)` 返回减少动态效果状态，唱片展开直接显示最终布局，黑胶旋转也按无障碍设计停止。

在用户要求恢复动效后，已将这台测试手机的三项动画缩放恢复为 `1`（正常速度），并在原有 0.1.9+11 安装包上录屏确认：

- 收藏唱片展开时有共享唱片移动、页面淡入、左侧轨道及右侧歌曲卡片进入过渡；返回时唱片回到陈列架。
- 本地 QA 音频播放期间黑胶持续旋转，暂停后保持在暂停时的角度。
- 无需重新构建或安装 APK；本次没有修改播放或混音逻辑。

如再次遇到所有动效消失，先检查 Android「开发者选项」中的窗口动画缩放、过渡动画缩放、Animator 时长缩放，以及系统无障碍的减少动态效果设置。视觉验收应在正常动画速度下进行；如果测试临时关闭了动画，完成后恢复测试前的设置。应用继续尊重用户主动选择的减少动态效果偏好，安装程序不自动修改系统设置。
